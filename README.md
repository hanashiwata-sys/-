# 日報自動化ツール

## 概要

CSVファイルを読み込み、必要なデータの抽出・チェックを行い、
日報用のExcelファイルとPDFファイルを自動作成するPythonプログラムです。

手作業によるデータ整理や帳票作成の手間を減らし、
日報作成業務の効率化を目的としています。

## 主な機能

- CSVファイルの自動読み込み
- 更新日時が最新のCSVファイルを自動選択
- UTF-8・CP932の文字コードに対応
- 必要な列が存在するかチェック
- 数量の未入力・数値以外のデータチェック
- Excelファイルの自動作成
- Excelの罫線・列幅・印刷設定の自動調整
- ExcelファイルからPDFファイルを自動作成
- エラー発生時にエラー内容を表示して処理を終了

## 動作環境

- OS:Windows 10 / 11
- Microsoft Excel:インストール必須

## 必要なライブラリ

| ライブラリ | 用途 |
| --- | --- |
| pandas | CSVファイルの読み込み・データ処理 |
| openpyxl | Excelファイルの作成・書式設定 |
| pywin32 | Microsoft Excelの操作・PDF出力 |

※glob、os、gc はPython標準ライブラリのため、別途インストールする必要はありません。

## フォルダ構成

```text
日報自動化/
├── CSVフォルダ/             # 入力用CSVファイルを保存
├── main.py                  # メインプログラム
├── README.md                # 説明書
├── <CSVファイル名>.xlsx     # 自動作成されるExcelファイル
└── <CSVファイル名>.pdf      # 自動作成されるPDFファイル
```

## CSVファイルの準備

1. 日報作成に使用するCSVファイルを用意します。
2. 用意したCSVファイルをCSVフォルダに保存します。
3. CSVファイルには、プログラムで指定された列が含まれている必要があります。
4. CSVファイルはUTF-8またはCP932の文字コードに対応しています。

## 使い方

1. VS Codeで本プログラムのフォルダを開きます。
2. ターミナルを開きます。
3. 以下のコマンドを実行します。

python main.py

4. プログラムがCSVフォルダ内の最新のCSVファイルを自動で読み込みます。
5. データのチェックが正常に完了すると、ExcelファイルとPDFファイルが自動作成されます。

## 出力ファイル

作成されたExcelファイルとPDFファイルは、プログラムのフォルダ内に保存されます。

出力ファイル名は、読み込んだCSVファイル名をもとに自動設定されます。

## エラー発生時の対応

以下のような場合は、エラーメッセージが表示され処理を終了します。

- CSVファイルが見つからない場合
- CSVファイルに必要な列が存在しない場合
- 数量が未入力、または数値以外の場合
- CSVファイルの形式に問題がある場合
- Excelファイルを保存できない場合

エラーメッセージを確認し、CSVファイルや保存先の状態を確認してから再実行してください。

## 注意事項

- PDFファイルの作成には、Microsoft Excelのインストールが必要です。
- Excelファイルを開いたまま実行すると、保存できない場合があります。
- CSVフォルダには、日報作成に使用するCSVファイルを保存してください。
